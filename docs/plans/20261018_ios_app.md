# iOS App

Status: moved out of `20261016_incremental_roadmap.md` on 2026-10-18

The desktop roadmap ends at the Mac app. Everything that exists only because
of the iPhone lives here, so the desktop work can finish, and be stress
tested, before any of it starts.

## Start condition

Not before the desktop app has been stress tested and the event format is
frozen (slice 15 of the roadmap). iOS is the second client of the same log, so
the freeze is the gate.

## Slices

Numbered as they were in the roadmap, so earlier links still make sense.

### 17. Dropbox API sync

- OAuth, token in Keychain, sync of the same per-device files over the API
- Sync behind a `Transport` protocol; in-memory fake for tests; two-device
  convergence tests
- Required for iOS, which has no Dropbox folder to watch

### 18. iOS app

- Same package; capture, Inbox and Today first, then the daily review
- Without the Apple Developer Program, a free provisioning profile expires
  every 7 days; decide then whether to pay
- Re-measure launch replay time on the phone, which is the slowest device
  (see slice 16 of the roadmap)

### CD-2. iOS CI/CD

- `xcodebuild` the iOS target in CI
- Distribution decided with slice 18: free 7-day provisioning from Xcode, or
  TestFlight with the Developer Program
